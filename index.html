Limits and rules
Simulation only: this page controls no API, has no effect on any real agent and reads no provider usage. Daily = rolling 24 hours, weekly = 7 days, monthly = 30 days, rate = calls per rolling 60 seconds. Each window is (now − duration, now]. Pending reservations never expire automatically. Settled actuals count from settlement time. A rejected reserve latches all future admissions; settlements may still record drift. A fresh simulation starts a separate hypothetical ledger. Nothing persists across reloads. A single serialized simulated stream cannot model distributed races, real durability or late provider billing. General information only, not financial advice.
